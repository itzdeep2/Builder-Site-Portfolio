# Builder-Site-Portfolio

A lightweight, terminal-inspired personal website and portfolio built from scratch with semantic HTML5 and vanilla CSS. 

Built as part of the **Hack Club Stardance** challenge to showcase personal projects, hardware builds, and networking experiments.

**Live Site:** [https://itzdeep2.github.io/Builder-Site-Portfolio/](https://itzdeep2.github.io/Builder-Site-Portfolio/)

---

## Features

- **Terminal Aesthetic:** Dark mode palette with custom monospace accents, prompt headers, and clean contrast.
- **Pure CSS Keyframe Animations:** 
  - Pulsing status indicator (`ONLINE / READY`).
  - Realistic blinking terminal prompt cursor.
  - Interactive transform zooms and elevation shadows on project cards.
- **Semantic Structure:** Modular layout using `<header>`, `<nav>`, `<main>`, `<section>`, and `<article>` tags.
- **Zero Framework Bloat:** 100% vanilla HTML5 and CSS—no runtime dependencies, external UI kits, or heavy JavaScript bundles.
- **GitHub Pages Ready:** Configured with `.nojekyll` bypass for static branch hosting.

---

## Featured Projects

- **Nebula SMP:** Self-hosted multiplayer game server with custom configurations, backup automation, and Tailscale mesh routing.
- **Hardware Keystroke Injector:** Programmable USB HID controller built on the Digispark ATtiny85 microcontroller for task automation.
- **Web Script Automation:** Custom DOM traversal and event automation scripts written for Tampermonkey.
